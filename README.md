# vamio.ch

Sito pubblico di **Vamio**, il gestionale svizzero di offerte e fatture QR-Bill con assistente AI (prodotto VAM Deco Sagl).

- Sito statico, pubblicato con GitHub Pages su https://vamio.ch
- Sorgenti grafiche e documenti: `~/kDrive/VAM Deco/Vamio/`
- Font Bricolage Grotesque e Figtree ospitati qui (nessuna chiamata a Google), licenza OFL
- Le schermate in `screenshot-demo/` mostrano dati di esempio inventati

## Struttura
- `index.html` — landing
- `legale/` — protezione dati, cookie
- `web-assets/` — font, favicon, immagine per le anteprime social
- `screenshot-demo/` — schermate del gestionale e pagine PDF di esempio
